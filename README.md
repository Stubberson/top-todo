# To-do list
[An intermediate JS project within the Odin Project.](https://www.theodinproject.com/lessons/node-path-javascript-todo-list) The focus is in solidifying the learnings about `npm`, Webpack, OOP, and SOLID.

This is/was the deepest dive so far into building a working application. My aim was to create an intuitive user-experience with a clean aesthetic. I also tapped into a few topics beyond the given assignment, such as creating a calendar, a time-picker, and toggling between a wide vs. narrow view.

There is still a lot that could be done and I am returning to this project to implement, for example
- task ordering by dragging and dropping,
- task-grouping,
- a back-end.
Some smaller improvements, like the look of the time-picker, are also on my mind. However, I have been developing this project for a few months now and thus want to move onto something else for a while, coming back to this at a later stage.

## Functionality
With the to-do list, you can:
- Create tasks for any day of the year.
    - A task has a header, a description, a due time and date, and toggles for indicating the importance and completion of a task.
- Create projects, which can include multiple tasks, for any day of the year.
- Switch between 'Today', 'Important', and 'Completed' views, getting an overview of your tasks today, important tasks, and completed tasks, respectively.
- Toggle the left and right sidebars, getting a clean view for your tasks.
